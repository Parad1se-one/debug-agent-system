# 现场问题反馈流程

随着客户数量的增长，现场问题反馈呈现越来越多的趋势，亟需规范流程。本文档详细阐述了问题反馈及处理方法，各环节责任人职责等，以保证问题能得到及时有效处理。



# 主要参与人及职责：

- **FAE团队**

    - 现场问题于飞书群内反馈并指定正确的负责人，配合产研收集必要资料；

    - 若疑似/明确为软件Bug或需求，提交JIRA并附上所需资料；

    - 问题修复后，升级现场版本并验证；

- **售后技术支持团队**

    - 微信售后群内需产研协助的问题，于飞书群内反馈并指定正确的负责人，配合产研收集必要资料；

    - 若疑似/明确为软件Bug或需求，提交JIRA并附上所需资料；

- **产研各类问题负责人\(参考**[**附表1**](https://example.feishu.cn/wiki/Wkohw5m4LiRToEkpmoZcxy5TnJd#share-Er0fdOmojo68YexWWBccCFGZnrh)**\)**

    - 第一时间确认问题是否归自己负责，非己范畴需转发对应责任人和交付PM；

    - 第一时间与问题提出者沟通细节，确定优先级并获取必要信息；

    - 高优问题及时修复；

    - 更新JIRA issue状态；

- **交付项目经理 **@工程师癸**，大客户项目经理**@米梓菲

    - JIRA问题，首次责任人指定错误率；

    - 项目发送日报，主要是：每日新增JIRA问题

    - 目前大客户有（项目负责人@米梓菲）：客户11、美国比特小鹿、客户18、环鸿、客户13、朗特、元昌（国讯）、兆兴博拓、丘钛微、客户05、客户14、一博科技



# 问题追踪平台：JIRA

问题提交方法参考[现场问题处理及故障报告创建指引](https://example.feishu.cn/docx/ZJrodpdTUo9082xUFH0cUnSdnvc#share-B5QRdPS3koRawyxkKvhcpcXtnJd)



# 流程总览：

1. FAE团队在现场遇到问题或售后技术支持团队遇到无法解决的问题时，需在**飞书群**里反馈并提交JIRA故障报告，**同时@正确的相关负责人**\(参考[附表1](https://example.feishu.cn/wiki/Wkohw5m4LiRToEkpmoZcxy5TnJd#share-Er0fdOmojo68YexWWBccCFGZnrh)\)。

2. 相关负责人在收到反馈后需在第一时间了解问题，确认是否属于自己负责范畴。若是，第一时间沟通清楚问题细节及优先级，并将Debug所需信息/日志/数据交代清楚，FAE/售后团队需配合澄清问题并收集所需资料，所有信息和资料需最终体现在JIRA里；若不属于自己的责任范围，需转发给正确的负责人并同时@对应项目经理。

3. 产研相关问题负责人根据与现场沟通的优先级处理问题，以不影响现场demo/生产为底线，尽快处理。原则上问题处理周期不应超过3周。

4. 交付项目经理需关注并收集问题被指定错误产研负责人的情况，根据错误发生频率，决定是否重新宣贯此文档。

5. 交付项目经理提供日报表格，记录每日新增问题等。
